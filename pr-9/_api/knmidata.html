async get_position(collection: str, coords: tuple[float, float], start_time: str | Timestamp | datetime | date | None = None, end_time: str | Timestamp | datetime | date | None = None, parameters: str | list[str] | None = None, output_format: Literal['CoverageJSON', 'GeoJSON'] = 'CoverageJSON', crs: str | None = None) → Dataset¶

Get station or point time-series via /collections/{id}/position.

Note: /position does server-side nearest-station matching, but only within a tolerance — it returns HTTP 404 (“The query returned no stations”) when no station is close enough to the point. For a reliable client-side nearest lookup use nearest_location(), then get_location() with the returned station id.

Parameters:

  • collection (str) – EDR collection ID.

  • coords (Coords) – Point coordinates (lon, lat).

  • start_time (TimeLike | None, default=None) – Start of the queried time interval (ISO-8601 string, pandas Timestamp, datetime, or date; naive values are assumed UTC). Sent as an RFC 3339 interval: with both start and end as ‘start/end’, with only start_time as ‘start/..’.

  • end_time (TimeLike | None, default=None) – End of the queried time interval. With only end_time given the interval ‘../end’ is sent. For a single instant, pass the same value as start_time and end_time.

  • parameters (list[str] | None, default=None) – Parameter name or list of parameter names to query (see collection metadata).

  • output_format (str, default="CoverageJSON") – Response format: ‘CoverageJSON’ or ‘GeoJSON’.

  • crs (str | None, default=None) – Coordinate reference system of coords, e.g. ‘EPSG:4326’.

Returns:

In-memory xarray dataset.

Return type:

xr.Dataset

async nearest_location(collection_id: str, coords: tuple[float, float]) → dict[str, Any]¶

Find the measurement location nearest to coords (client-side).

/position does server-side nearest-station matching but only within a tolerance — it returns HTTP 404 “The query returned no stations” when no station is close enough. This helper always returns the closest station: it fetches /locations and computes haversine distances.

Parameters:

  • collection_id (str) – EDR collection ID.

  • coords (Coords) – Point coordinates (lon, lat).

Returns:

The nearest location: {‘id’, ‘name’, ‘coordinates’, ‘distance_km’, ‘properties’}.

dict[str, Any]

Bases: object

Client for the KNMI Open Data API (file-based bulk downloads).

Covers the whole Open Data workflow: list_files (catalog with cursor pagination and time filtering), get_download_url (presigned S3 URL per file), stream_file/download_files (atomic concurrent downloads to disk), open_dataset (open files already on disk into an xarray.Dataset), and get_dataset (list + download-if-missing + open in one call). Access it via client.opendata, or instantiate directly with your own transport/auth.

async get_dataset(dataset_name: str, dataset_version: str, start_time: str | Timestamp | datetime | date | None = None, end_time: str | Timestamp | datetime | date | None = None, cache_dir: str | Path | None = None, file_pattern: str | None = None, max_files: int | None = None, engine: str = 'h5netcdf', combine: Literal['by_coords', 'nested', 'no_conflicts'] = 'by_coords', concat_dim: str | None = None, **open_dataset_kwargs: Any) → Dataset¶

Get matching archive files via Open Data and assemble an xarray.Dataset.

If cache_dir is given, files already on disk (matching the catalog size) are reused instead of re-downloaded, and the dataset is opened lazily from disk via open_dataset. If cache_dir is None, files are downloaded to a temporary directory, loaded into memory, and removed again.

Parameters:

  • dataset_name (str) – KNMI dataset name.

  • dataset_version (str) – Dataset version identifier.

  • start_time (TimeLike | None, default=None) – Start timestamp (ISO-8601 string, pandas Timestamp, datetime, or date; naive values are assumed UTC).

  • end_time (TimeLike | None, default=None) – End timestamp (TimeLike, see start_time).

  • cache_dir (PathLike | None, default=None) – Local folder to cache downloaded NetCDF/HDF5 files in. If None, files are downloaded to a temporary directory and loaded into memory.

  • file_pattern (str | None, default=None) – Optional regular expression to keep only matching file names.

  • max_files (int | None, default=None) – Maximum number of files to download (after listing, ascending order).

  • engine (str, default="h5netcdf") – Xarray backend engine used to open each file (see files_to_dataset).

  • combine (CombineMethod, default="by_coords") – How to combine the per-file datasets (see files_to_dataset).

  • concat_dim (str | None, default=None) – Dimension to concatenate along when combine=’nested’.

  • **open_dataset_kwargs (Any) – Additional keyword arguments passed to xarray.open_dataset per file.

Returns:

Combined multidimensional dataset.

Return type:

xr.Dataset

Raises:

NoFilesFoundError – If the query matches no files.

class knmidata.AsyncTransport(max_concurrency: int = 15, timeout: float = 60.0, max_retries: int = 3, retry_backoff: float = 0.5)¶

Bases: object

Encapsulates an httpx.AsyncClient bounded by a concurrency semaphore.

All requests should go through request() (or stream()), which applies the semaphore, retries transient failures with backoff, and maps HTTP errors onto the knmidata exception hierarchy.

Parameters:

  • max_concurrency (int, default=15) – Maximum number of concurrent network requests permitted across the session.

  • timeout (float, default=60.0) – Read timeout in seconds (per chunk for streamed downloads).

  • max_retries (int, default=3) – Number of retries for transient failures (429/5xx/transport errors).

  • retry_backoff (float, default=0.5) – Base backoff in seconds; the actual delay is retry_backoff * 2**attempt plus jitter, and honors the Retry-After response header when present.
